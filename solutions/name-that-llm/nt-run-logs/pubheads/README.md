# NTL public heads copy

This dataset is an unchanged copy of public Kaggle inputs (LoRA adapters and classifier heads) for the Name That LLM competition. It keeps fixed files, so a notebook gets the same weights even if an original changes or is deleted. All credit goes to the original authors. Please cite and upvote the originals.
