Adding a few clarifications regarding the competition:
- **Kaggle Benchmarks proxy quota & public datasets:** It is not the intent of the Benchmarks proxy quota to be used for non-benchmarking work; however, we will not penalize participants who have already used it (no action is needed on earlier submissions). Public community datasets on Kaggle (including those generated via the proxy) are fine to train on.
- **Self-generated data:** Self-generated training data (within reasonable cost, as noted earlier) does not need to be made public, so there is no publication deadline for it.
- **Public pre-trained weights:** Additionally, model weights (such as LoRA adapters) that are publicly available to all participants on Kaggle are fine to use.

=== [1] ? (2026-10-28 20:53:13.060000) votes=1 ===
Thanks for the questions! Here is some clarification on these points:

- **Data generation:** This is intended to be an ML prediction competition, not a data generation competition. Effectively "buying" more training data via token spend beyond the value of a possible prize ($5k) would be considered unreasonable.
- **Kaggle Benchmarks quota:**  The Benchmarks proxy quota is reserved for benchmark evaluation runs, not for generating competition training data *please see the answer below*
- **Winner license:** Yes. An OSI-approved open source license for the write-up and documentation is acceptable.
- **Existing public datasets:** Existing public community datasets on Kaggle are fine to train on.
